# Smart Child Registration — ระบบจองคิวและเก็บข้อมูลเด็ก

เว็บแอปสำหรับเจ้าหน้าที่ ใช้ลงทะเบียนข้อมูลเด็ก จองคิวรับบริการ และเรียกคิวขึ้นจอ

- **หน้าเว็บ** อยู่บน GitHub Pages (โฟลเดอร์ `docs/`)
- **ข้อมูล** เก็บใน Google Sheet ของหน่วยงาน อ่าน/เขียนผ่าน Google Apps Script (`apps-script/Code.gs`)
- ไม่มีข้อมูลเด็กอยู่ใน GitHub เลย ใน GitHub มีแค่โค้ด

## ความสามารถ
- **คิววันนี้**: ดูคิวของวันนี้ กดเรียกคิว / เสร็จสิ้น / ยกเลิก
- **ข้อมูลเด็ก**: ลงทะเบียน ค้นหา แก้ไข ลบ ออก HN ให้อัตโนมัติ ตรวจเลขบัตรประชาชน คำนวณอายุและ BMI เตือนประวัติแพ้ยา
- **จองคิว**: เลือกเด็ก วันที่ บริการ และช่วงเวลา กันจองเกินจำนวนและกันจองซ้ำในวันเดียวกัน
- **จอเรียกคิว** (`display.html`): เปิดบนทีวีหน้าห้อง มีเสียงเรียกคิวภาษาไทย แสดงเฉพาะชื่อเล่น

## ติดตั้ง (ทำครั้งเดียว)

### ขั้นที่ 1: สร้าง Google Sheet และ Apps Script
1. เปิด https://sheets.new เพื่อสร้างชีตใหม่ ตั้งชื่อเช่น `ข้อมูลเด็ก - Smart Child Registration`
2. เมนู **ส่วนขยาย > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs) กดบันทึก
4. ตั้งรหัสผ่านเจ้าหน้าที่: กด **ตั้งค่าโปรเจกต์** (รูปเฟือง) > **คุณสมบัติของสคริปต์** > **เพิ่มคุณสมบัติของสคริปต์**
   - คุณสมบัติ: `ACCESS_KEY`
   - ค่า: รหัสผ่านที่ต้องการ **ควรยาว 12 ตัวขึ้นไปและเดายาก** เพราะใครที่มีรหัสนี้จะเห็นข้อมูลเด็กทั้งหมด
5. ในหน้าเดียวกัน เปลี่ยน **เขตเวลา** เป็น `(GMT+07:00) Bangkok`
6. กลับไปหน้าแก้ไขโค้ด เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **เรียกใช้**
   ครั้งแรก Google จะขอสิทธิ์ ให้กด **ตรวจสอบสิทธิ์ > เลือกบัญชี > ขั้นสูง > ไปที่โปรเจกต์ (ไม่ปลอดภัย) > อนุญาต**
   (คำว่า "ไม่ปลอดภัย" ขึ้นเพราะเป็นสคริปต์ที่เราเขียนเอง Google ยังไม่ได้ตรวจสอบ)
   เมื่อเสร็จ จะมีชีต `Children` และ `Bookings` เพิ่มขึ้นมา

### ขั้นที่ 2: เปิดใช้เป็นเว็บแอป
1. ใน Apps Script กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. กดรูปเฟืองข้าง "เลือกประเภท" แล้วเลือก **เว็บแอป**
3. ตั้งค่า **ดำเนินการในฐานะ: ฉัน** และ **ผู้มีสิทธิ์เข้าถึง: ทุกคน**
   (ต้องเลือก "ทุกคน" เพื่อให้หน้าเว็บบน GitHub เรียกได้ ส่วนข้อมูลมีรหัสผ่าน `ACCESS_KEY` ป้องกันไว้)
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 3: ใส่ URL ลงในหน้าเว็บ
แก้ไฟล์ [`docs/config.js`](docs/config.js) แล้วใส่ URL ที่คัดลอกมา:
```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
};
```
แก้บนเว็บ GitHub ได้เลย (กดรูปดินสอ แล้ว Commit) ถ้าไม่ใส่ หน้าเข้าสู่ระบบจะให้กรอก URL เองในแต่ละเครื่อง

### ขั้นที่ 4: เปิด GitHub Pages
ใน repository บน GitHub ไปที่ **Settings > Pages**
- Source: **Deploy from a branch**
- Branch: **main** โฟลเดอร์ **/docs** แล้วกด **Save**

รอประมาณ 1–2 นาที จะได้ลิงก์ เช่น `https://<ชื่อบัญชี>.github.io/smart-child-registration/`

## การใช้งาน
- เปิดลิงก์ GitHub Pages แล้วใส่รหัสผ่านเจ้าหน้าที่
- ติ๊ก "จำรหัสผ่าน" เฉพาะในเครื่องของหน่วยงานเท่านั้น
- จอเรียกคิว: เปิด `…/display.html` บนทีวี ใส่รหัสผ่านครั้งเดียว แล้วกด F11 เพื่อเต็มจอ
- Google Sheet ตอบช้ากว่าฐานข้อมูลทั่วไป แต่ละคำสั่งใช้เวลาประมาณ 1–3 วินาที

## เมื่อแก้โค้ด Apps Script
หลังวางโค้ดใหม่ ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (รูปดินสอ) > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้**
URL จะยังเป็นอันเดิม ถ้าไม่ทำขั้นนี้ เว็บจะยังเรียกโค้ดเวอร์ชันเก่าอยู่

## ปรับแต่ง
แก้ที่ต้นไฟล์ `Code.gs`:
- `SLOTS`: ช่วงเวลาที่เปิดให้จอง
- `SLOT_CAPACITY`: จำนวนเด็กต่อช่วงเวลา (ค่าเริ่มต้น 3)
- `SERVICES`: รายการบริการ

## ความปลอดภัยของข้อมูล
- ข้อมูลเด็กเป็นข้อมูลส่วนบุคคลตาม PDPA **อย่าแชร์ Google Sheet ให้คนนอก** และอย่าใส่รหัสผ่านลงใน GitHub
- ถ้าสงสัยว่ารหัสรั่ว ให้เปลี่ยนค่า `ACCESS_KEY` ใน Apps Script ได้ทันที ไม่ต้อง deploy ใหม่
- **ห้ามแก้ชื่อหัวคอลัมน์แถวแรก** ในชีต `Children` และ `Bookings` เพราะระบบใช้หัวคอลัมน์เหล่านี้อ่านข้อมูล
- สำรองข้อมูลได้จาก **ไฟล์ > ดาวน์โหลด > Microsoft Excel**
