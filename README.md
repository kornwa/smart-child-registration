# Smart Child Registration — ระบบจองคิวเข้าเรียนเนอสเซอรี่

ผู้ปกครองสมัครเข้าคิวออนไลน์และเช็กลำดับคิวได้เอง เจ้าหน้าที่รับเด็กเข้าเรียนตามลำดับเมื่อมีที่ว่าง

- **หน้าเว็บ**: GitHub Pages (โฟลเดอร์ `docs/`) → https://kornwa.github.io/smart-child-registration/
- **ข้อมูล**: Google Sheet ของหน่วยงาน อ่าน/เขียนผ่าน Google Apps Script (`apps-script/Code.gs`)
- ไม่มีข้อมูลเด็กอยู่ใน GitHub (มีแค่โค้ด)

## กลุ่มและห้องเรียน
| กลุ่ม | อายุ ณ วันเริ่มเรียน | ห้อง |
|---|---|---|
| กลุ่ม 1 | 6 สัปดาห์ – 1 ขวบ | 1 |
| กลุ่ม 2 | 1 – 2 ขวบ | 2/1, 2/2 |
| กลุ่ม 3 | 2 – 3 ขวบ | 3/1, 3/2, 3/3 |

ระบบคำนวณอายุ ณ "วันที่ต้องการให้เริ่มเรียน" แล้วจัดกลุ่มให้อัตโนมัติ เลขคิวแยกตามกลุ่ม (เช่น `2-007`)
จำนวนที่นั่งแต่ละห้องตั้งได้ที่หน้าเจ้าหน้าที่ > ตั้งค่าห้อง (หรือแก้ในชีต `Rooms`)

## หน้าเว็บ
| หน้า | ใครใช้ | ทำอะไรได้ | เข้าด้วย |
|---|---|---|---|
| `index.html` | ทุกคน | เลือกผู้ปกครอง / เจ้าหน้าที่ | - |
| `parent.html` | ผู้ปกครอง | สมัครเข้าคิว, ดูลำดับคิว, ยกเลิก, ต่อคิวใหม่, ดูข้อมูลลูก | เลขบัตรประชาชนลูกหรือ HN + เบอร์โทรที่ใช้สมัคร |
| `staff.html` | เจ้าหน้าที่ | คิวรอเข้าเรียน (รับเข้าเรียน/ยกเลิก), ห้องเรียน (ย้ายห้อง/ออก), ข้อมูลเด็ก, ตั้งค่าห้อง | รหัสผ่านเจ้าหน้าที่ |

สถานะคิว: **รอคิว** → **เข้าเรียนแล้ว** (มีห้อง) → **ออกแล้ว** หรือ **ยกเลิก** (คืนเข้าคิวได้ โดยได้ลำดับเดิมตามเลขคิว)

## ความปลอดภัยของข้อมูล
- ผู้ปกครองเห็นเฉพาะข้อมูลลูกตัวเอง ไม่เห็นเลขบัตรหรือที่อยู่ กรอกผิด 5 ครั้งล็อก 15 นาที
- สมัครออนไลน์ต้องกดยินยอมให้เก็บข้อมูล (PDPA) และจำกัด 60 ใบสมัครต่อชั่วโมงกันสแปม
- รหัสผ่านเจ้าหน้าที่ตั้ง/เปลี่ยนได้ที่เมนู **🧒 ระบบจองคิว** ในชีต
- **อย่าแชร์ Google Sheet ให้คนนอก** และ **ห้ามแก้ชื่อหัวคอลัมน์แถวแรก** ในชีต `Children`, `Applications`, `Rooms`
- สำรองข้อมูล: ในชีต ไฟล์ > ดาวน์โหลด > Microsoft Excel

## แก้โค้ดหลังบ้าน (สำหรับผู้ดูแล)
ใช้ [clasp](https://github.com/google/clasp) ในโฟลเดอร์ `apps-script/` (ไฟล์ `.clasp.json` ไม่ได้อยู่ใน git):
```
clasp push -f
clasp update-deployment <deploymentId>   # ใช้ id เดิม URL จะไม่เปลี่ยน
```
ค่าที่ปรับได้อยู่ต้นไฟล์ `Code.gs`: `GROUPS`, `DEFAULT_ROOMS`, `START_AHEAD_DAYS` และท้ายไฟล์ `PARENT_MAX_FAILS`, `APPLY_LIMIT_HOURLY`
